## Cross-cutting stop conditions (apply at every tier)

1. Do not progress to complex models if a bias-corrected NBM/ensemble cannot
   improve probability scoring over raw NWP.
2. Do not build execution logic if forecast-market discrepancies fail to
   predict subsequent returns beyond transaction costs.
3. Do not scale exposure if gains disappear under modest latency/slippage
   assumptions.
4. Do not claim a strategy-level edge until it survives an untouched
   walk-forward period plus multiple-testing-aware inference.
5. Model-selection hierarchy: **calibration → CRPS/Brier → net economic
   utility → complexity**, not "highest backtest Sharpe." `multiple_testing.py`
   now provides a dependence-aware max-statistic check before selecting among
   many candidate return series.
